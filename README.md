# ppro_cutNum

Adobe Premiere Pro で V1 に配置されたカットを走査し、各カット番号を画面に表示するための ExtendScript (JSX) を収録しています。

## スクリプト

- `scripts/cut_number_overlay.jsx`
  - アクティブなシーケンスの V1 トラックを読み込み、各クリップの開始〜終了に Essential Graphics のテキストを配置します。
  - テキストには `Cut 1`, `Cut 2`, ... のようにカット番号が自動で割り当てられます。
  - 既にスクリプトが作成したオーバーレイ (`[CutNum]` プレフィックス付き) が存在する場合は実行前に削除します。

## 使い方

1. Premiere Pro で対象のプロジェクトとシーケンスを開きます。
2. カットが配置されているシーケンスをアクティブにし、V1 にクリップが並んでいることを確認します。
3. `ファイル > スクリプト > スクリプトの実行...` から `scripts/cut_number_overlay.jsx` を選択します。
4. スクリプトが V2 以降のトラックに番号付きテキストのオーバーレイを自動で作成します。

> **注意:** スクリプトは Essential Graphics API を使用します。Premiere Pro 14.0 以降で動作確認を想定しています。
